# 嘎语翻译器

> 把中文变成鸭子听得懂、也发得出的声音，再把鸭叫听回中文。

嘎语翻译器是一个中文 ⇄ **嘎语**（鸭子语）的双向翻译器。它不是把每个字换成"嘎"：嘎语是一门为鸭叫设计的迷你语言，每一声"嘎"的**明暗、升降、长短**都带着意思。所以合成出来的鸭叫可以被录下来，再解码回鸭语和中文，适合机器人之间、机器人和电脑之间的闭环通信。

![嘎语翻译器 Web 界面](docs/screenshot.png)

## 它是什么

- **12 个音节就是 12 种鸭叫**：音色（亮"嘎" `k` / 暗"呱" `w`）× 走势（降 `a` / 升 `i` / 平 `o`）× 时长（短 / 长）
- **约 60 个词、双向唯一**：中文能翻成鸭语，鸭语也能翻回中文
- **真的像鸭子**：音色从真实绿头鸭录音里提取，沙哑感和音高由程序精确控制
- **听得懂**：解码器纯信号处理实现，经过模拟的喇叭、房间混响和噪声仍能准确识别
- **完全离线**：不需要云端 TTS，也不需要大模型

## 能做什么

- 中文 -> 嘎语，附逐词直译和鸭叫音频
- 嘎语 -> 中文
- 鸭叫录音 -> 嘎语 -> 中文（上传 WAV 或网页直接录音）
- 四种音色（幼鸭、成鸭、愤怒鸭、温柔鸭）和五种情绪，都不影响解码
- 机器人小喇叭输出预设（`--target robot`）
- CLI、REPL、Web 页面、Python API

## 翻译示例

| 中文 | 嘎语 | 直译 |
| --- | --- | --- |
| 你吃了吗？ | `wa waka koo ki?` | 你 吃 了 吗 |
| 我饿了 | `ka wakaa kii` | 我 食物 要 |
| 你去哪里？ | `wa kiwo wiiko ki?` | 你 哪里 去 吗 |
| 危险！ | `kaakaa!` | 危险 |
| 明天要下雨 | `kiwoo waako kiko` | 明天 下雨 会 |
| 我们去水边吧 | `kaka waa woko wiiko` | 我们 水边 在 去 |

## 快速开始

需要 Python 3.11+ 和 [uv](https://docs.astral.sh/uv/)。

```bash
cd E:\xgo-duck\duck-language
uv sync
uv run duck-web
```

浏览器打开 `http://127.0.0.1:8000`，在"中 → 鸭 / 鸭 → 中 / 听 → 中"之间切换。

命令行：

```bash
uv run duck "你去哪里？"
uv run duck --reverse "wa kiwo wiiko ki?"
uv run duck --listen out\some.wav
```
